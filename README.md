# 🛡️ TryHackMe SOC Level 1

Welcome to my **TryHackMe SOC Level 1 learning portfolio**.

This repository documents my hands-on journey through the **TryHackMe SOC Level 1** learning path. It contains structured notes, lab documentation, screenshots, commands, investigation techniques, and key defensive security concepts developed through practical SOC exercises.

# 🔎 Investigation Workflow

The practical SOC workflow developed throughout this repository follows a structured approach:

```text
Alert
  │
  ▼
Triage
  │
  ▼
Validate
  │
  ▼
Enrich
  │
  ▼
Investigate
  │
  ▼
Correlate Evidence
  │
  ▼
Determine Severity
  │
  ▼
Escalate / Respond
  │
  ▼
Document Findings
```

This workflow provides a structured approach for analysing security alerts and supporting effective incident response.
